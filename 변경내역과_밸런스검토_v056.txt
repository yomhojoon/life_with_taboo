연명 강령 v0.5.6 변경 사항 및 밸런스 검토
기준: GitHub life_with_taboo v0.5.5 (9317d85058...)

[1] 도감 전면 삭제
- 메인 화면의 도감 링크 2개 모두 삭제
- 게임 내 도감 화면과 스크립트, 관련 CSS 삭제
- 별도의 gallery.html 페이지, 생성 스크립트 및 프리뷰 파일은 배포에서 제거
- 문자/유령/유품 관리 목록은 도감이 아니므로 그대로 유지

[2] 표시 수치
- 자금, 건강, 정신력, 신기, 행운, 세부 운, 변화량은 소수 이하가 화면에 보이지 않도록 반올림 표시
- 엔진의 내부 계산 정밀도(확률, 연속 식사 계수 등)는 유지
- 소수 단위 보상만 있었던 유품 '어떤 현관 열쇠'의 알바 시 재물운 +0.1 제거
- UI의 소수점 표시 변경은 과거 저장 데이터를 변조하지 않음

[3] 진행 중 문자/유령 관리
- 일정 편성 중과 하루 자동 진행 중 모두 가능
- 사건 선택지가 열린 상태에서도 시도 가능
- 문자/유령 확인을 별도 팝업으로 표시, 기존 선택지는 임시 보관
- 완료/취소/결과 확인 후 기존 사건과 장면으로 복구
- 자동 진행 중 관리 요청 시 자동 진행 일시 정지, 직접 재개 가능
- 하루 문자 제거 시도는 3회(실패도 1회 차감) 유지
- '야옹야옹' 제거 불가, 지박/빙의 유령 직접 해방 불가 유지

[4] 문자 제거 성공률 (기존 → 변경, 기본치)
0등급: 93% → 90%
1등급: 78% → 75%
2등급: 58% → 55%
3등급: 33% → 30%
- 전 등급 성공률 -3%p, 파생 지속 효과의 성공률 보정은 그대로 적용
- 해방(유령) 실패 확률은 변경하지 않음

[5] 조사 용어 자연화
'해방 매듭법을 기록한다' → '해방을 돕는 부적 제작법을 기록한다'
'해방 보호 매듭' → '해방 부적'
기능: 다음 해방의 실패 위험을 13%p 감소시키는 사용 가능한 보호 효과 (최대 3개 저장)
관련 기록/이벤트 표시와 소비 로그를 통일

[6] 상시 효과 한눈에 보기
관리 영역에 '지속 효과' 추가. 문자스킬/유령/유품의 적용 중 효과, 일일 기본 합산, 조건부/행동별 보너스 확인.
단, 강제 비공개 문자 '야옹야옹'은 기존 게임 컨셉대로 설명을 노출하지 않음. 일일 합산에서도 효과 제외하며 비공개 효과가 존재한다고 명시.
유령의 지박/빙의 상태와 빙의 중 추가 일일 효과도 표시.
