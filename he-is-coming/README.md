# 그가 오고 있습니다

검은 모니터 한 대와 자유 입력으로 진행하는 텍스트 명령형 공포 게임입니다.

- **플레이:** https://yomhojoon.github.io/life_with_taboo/he-is-coming/
- **실행:** `index.html`과 같은 폴더의 네 가지 오프라인 스크립트(`extras.js`, `question-catalog.js`, `routes.js`, `room.js`). GitHub Pages에서 추가 설치나 유료 API 없이 실행
- **시간:** 시작 후 150초. 100KM에서 1KM당 1.5초씩 접근
- **경고:** 20KM 간격, 마지막 10초는 1초 간격
- **판정:** 요청 처리 1~2초. 공격 및 이동의 후속 경과는 다시 1~2초 후 출력
- **질문:** 장소·실내·출입문·플레이어 기록은 조회 가능. '그'에 대해서는 스무고개 형식만 허용
- **금기:** 연구 관련 정보, 직접 접촉, 방 또는 게임 이탈, 방 파괴, 도시 파괴 등
- **종료:** 플레이어가 사망하면 즉시 실패. 모니터 전원 공급 차단 시 별도 생존 엔딩
- **입력:** 모바일 화면 키보드를 고려한 입력창 위치 조절
- **소리:** Web Audio API로 비프음·팬 소음 생성

## 무료 오프라인 문장 인식

기본 판별 엔진은 네트워크를 사용하지 않습니다. 동의어와 지칭 표현(그, 그놈, 저 녀석, 추격자 등), 조사·어미 차이, 자연스러운 질문/명령 변형을 조합해 인식합니다. 이전에 정한 금기 규칙은 문장 해석보다 우선 처리됩니다. **생성형 AI나 의미 임베딩 모델이 연결된 것은 아니며**, 전혀 새로운 표현에는 오판 또는 이해 불가가 발생할 수 있습니다. 알려지지 않은 세계관 사실에 대해서는 답변을 추측하지 않습니다.

### 회귀 검사

```bash
node he-is-coming/tests/offline-regression.cjs
node he-is-coming/tests/extended-content.cjs
node he-is-coming/tests/branching-endings.cjs
node he-is-coming/tests/permanent-room.cjs
```

기존 규칙 검사 **8,669개**, 확장 콘텐츠 검사 **2,209개**, 분기 엔딩 검사 **219개**, 방 고정 시설 검사 **157개** 등 **총 11,254개 시나리오**를 검사합니다. Node.js 외부 패키지나 API 키가 필요하지 않습니다.

## 물품 지급과 단말기 질문

- `물 좀 줘`, `식수가 필요해`, `담요 하나 줄래?`, `빵을 가져와`, `총 지급해줘`, `커피 한 잔 부탁해` 등 여러 말투와 띄어쓰기를 같은 물품 요청으로 분류하고 요청 물품을 간단하게 지급 보고합니다.
- `너 누구야?`, `너희는 누구야?`, `누가 너를 만들었어?`, `너네는 뭐하는 조직이야?`, `너는 뭘 할 수 있어?`, `너 내 말 듣고 있어?` 등에는 단말기의 기능 또는 운영 정보 조회 제한에 관한 응답을 제공합니다.
- 금지 행동을 수행하기 위한 물품 지급과 '그'에게 물품을 직접 전달하는 명령은 승인하지 않습니다.
- **모든 입력은 로컬 정규표현식 판별로 처리됩니다. 생성형 AI를 사용하지 않으며 비용이 들지 않습니다.**

## 파생형 질문 및 문맥

- `그가 오는 것에 조건이 있나?`와 접근·추적·출현·이동 조건의 존재 여부를 묻는 다양한 문장에 예/아니요로 답변합니다. **조건의 세부 내용을 직접 알려 달라는 열린 질문은 제한**합니다.
- `그는 식물인가?`, `그는 나무야?`, `그는 식물이 아니니?` 등의 종류 분류 질문에 답변합니다. 식물의 외형을 닮았는지, 광합성을 하는지처럼 확인되지 않은 명제는 임의로 단정하지 않습니다.
- `뭘 할 수 있지?`, `어떤 명령이 가능해?`, `내가 뭘 해야 하지?` 등에는 허용된 요청 범주를 안내합니다. 문장의 표현에 따라 여러 안내 메시지 중 하나를 출력합니다.
- `지금 뭐해`, `너는 지금 뭐해?`, `나는 지금 뭘 하고 있어?`, `너희는 지금 뭐해?`는 **단말기·사용자·운영 주체**를 구분하여 답변합니다. 운영 주체의 현재 활동을 추측하지 않습니다.
- 앞선 질문의 주제를 세션 중 잠시 유지하여 `그러면 나무야?`, `그럼 어떤 조건인데?` 같은 짧은 후속 질문도 이전 대상을 참조할 수 있습니다. 재시작하면 대화 문맥은 초기화됩니다.
- 기본 기능은 여전히 무료 오프라인 규칙 엔진입니다. 모든 자연어 문장을 이해할 수 있는 생성형 AI는 아닙니다.

## 결말 단서의 단계적 확인

- `약점이 있나?`, `그에게 물리적인 약점이 있나?`, `그는 빈틈이 있나?` 등을 처리하며, **개체 자체의 물리적 피해**와 **접근 조건의 취약성**을 구분합니다.
- `뭔가를 하면 멈춰?`, `그를 멈출 수 있나?`, `추격을 끝낼 수 있나?` 등에서 **개체를 직접 멈춤**과 **현재 추격이 중단됨**을 다르게 판정합니다.
- 추격 대상, 빛, 화면·장치의 상태, 제어 방식, 별도 광원, 밝기와 전원 차단에 관한 예/아니요 확인형 질문을 추가했습니다. 잘못된 방법을 긍정하지 않도록 반례도 검사합니다.
- `힌트 줘`, `단서 하나 줘`, `힌트 더 줘` 등의 요청은 회차별로 총 5단계까지 간접 단서를 제공합니다. 게임을 새로 시작하면 단서 단계도 초기화됩니다.
- `약점이 뭐야?`, `어떻게 멈춰?`, `정답을 알려줘` 같은 질문에는 세계관의 정답을 곧바로 공개하지 않으며, 가능한 경우 예/아니요 확인형으로 유도합니다.

## 추가 콘텐츠

- **질문·요구 320개:** 물질·생물·추격 조건·약점·빛·전원·시간·방·기록·단말기·물품·돌발 상황 등 32개의 의미군, 각 10개 사례. '혹시', '궁금한데' 등 앞말 변화도 인식합니다.
- **소지품 77종 × 8행동 = 616개 상호작용:** 물, 음식, 약, 붕대, 의료기, 휴대폰, 책, 망치, 손전등, 라디오, 지도 등. 물품을 먼저 요청하면 소지품 목록에 추가되며, 물품 이름과 행동을 입력해야 실제로 사용합니다. 소모품은 사용 시 수량이 줄어듭니다.
- **무작위 돌발 상황 완전 제거:** 예전 12종은 모두 등장하지 않습니다. 무관한 이벤트의 시간 제한이나 자동 스폰, 랜덤 획득도 없습니다.
- **방에 항상 존재하는 시설 5종:** 잠긴 정비함, 비상 장비함, 관리 콘솔, 모니터 전원선, 경비 복식 안내가 화면 상단에 항상 표시됩니다. 각 시설의 버튼을 누르거나 직접 질문하고 조작할 수 있습니다.
- **정비함:** 락픽, 만능열쇠, 드라이버, 지렛대, 니퍼 등의 공구나 부식성·고열 물질로 잠금을 해제한 뒤 `정비함에서 해킹 툴 꺼내`로 해킹 도구를 획득합니다. 내용물은 한 번만 가져갈 수 있습니다.
- **비상 장비함:** 장비함을 열고 `단검 꺼내`로 단검을 한 번 획득합니다.
- **관리 콘솔:** 자체 해킹 또는 해킹 도구로 관리자 접근 권한을 얻어도 문은 즉시 열리지 않습니다. 광원 동기화 시험 제12호의 정리된 내부 실험 기록이나 `불을 켜지 말라`는 안전 행동 지침을 열람하거나 문 개방을 선택할 수 있습니다.
- **모니터 전원선:** 무엇에 연결되어 있는지 조회할 수 있습니다. 날붙이·부식성 물질·고열 장비로 끊으면 모니터가 종료되고, 이후 문을 물리적으로 열 수 있습니다. 금속 날붙이를 절연 장갑·고무장갑·절연테이프 없이 사용하면 감전사합니다. 단말기 종료 후에는 물리 행동만 허용됩니다.
- **경비 복식 규정:** 경비제복, 경비모, 경비화를 모두 실제로 착용한 채 콘솔 보안을 해제하고 나가면 변장 탈출 엔딩을 볼 수 있습니다. 단순 소지만으로는 인정되지 않습니다.
- **엔딩 대화 기록:** 게임이 끝난 다음 '대화 기록 보기'에서 전체 로그를 PNG 이미지로 확인할 수 있으며 '기록 PNG 저장'으로 로컬 다운로드할 수 있습니다. 기록 이미지를 외부 서버에 보내지 않습니다.
- **물질 분류:** '무기물인가?'와 '유기물인가?' 등을 구분해 답합니다. 확정할 수 없는 생물학적 분류는 답변을 지어내지 않습니다.
- **시작 안내:** '응답을 관찰하고 방법을 찾으십시오.'를 별도 줄로 배치했습니다. 힌트의 질문 형식 안내도 명확하게 교정했습니다.

## 추가 분기 엔딩 및 사망 통계

- **보안 장치 해킹:** 자체 해킹·해킹 장비·노트북은 우선 콘솔 접근 권한을 확보합니다. 이후 자료를 읽거나 별도로 문을 열어야 합니다. EMP를 사용한 기존 잠금 해제 경로도 유지됩니다.
- **출입 후 판정:** 문이 열리기 전에는 나갈 수 없습니다. 비무장이면 제압, 무기를 지참하면 무장 탈출합니다. 단, 콘솔 해킹 경로에서 복식을 모두 갖춰 입었다면 변장 탈출 엔딩이 우선합니다.
- **모든 외부 조명 동시 점등:** 이 방 밖의 모든 장소에서 불을 켜면 접근 거리와 남은 초가 불일치하는 자동 경고가 4~5회 나오고 세계 혼돈 엔딩으로 이동합니다. 한 곳의 조명을 켜는 것은 해당하지 않습니다.
- **특정 사망 원인:** 독약을 섭취하거나 노출된 고압 전선에 맨손으로 접촉하는 등 위험 행동을 선택하면 사망 원인이 엔딩에 기록됩니다. 기존 사망 요청도 원인 단서를 반영합니다.
- **세션 통계:** 엔딩에는 경과 시간, 입력 수, 승인·반려, 물품 획득·사용, 방 내부 시설 조작, 전선 절단, 해킹 시도와 힌트 확인 횟수가 포함됩니다. PNG 대화 기록에도 함께 남습니다.
- **기존 엔딩:** 모니터 전원 차단 생존, 추격자 도착 및 일반 사망 조건은 유지합니다.

## 선택형 AI 중계

별도 운영 서버를 연결하면 추가 의미 판별이 가능하지만 **기본 배포본은 비활성화**되어 있습니다. 현재 게임의 정상 사용과 테스트에는 과금이 없습니다. 공개 GitHub Pages에는 API 비밀 키를 넣지 마십시오. 필요한 경우 [별도 AI 중계 안내](ai-worker/README.md)를 참조할 수 있습니다.
