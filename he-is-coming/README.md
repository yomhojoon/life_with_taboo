# 그가 오고 있습니다

검은 모니터 하나를 통해 자유 입력으로 진행하는 실시간 텍스트 공포 게임입니다.

- 배포 페이지: https://yomhojoon.github.io/life_with_taboo/he-is-coming/
- 시작 버튼을 누르기 전에는 타이머가 멈춰 있습니다.
- 최초 거리: 100KM. 1KM 이동에 1.5초가 소요되므로 도착까지 150초입니다.
- 거리 상태는 **20m마다** 갱신됩니다(30ms 간격). 대화 기록을 5,000개로 도배하지 않도록 현재 거리 경고 한 줄을 갱신하며, 주요 구간과 마지막 10초는 별도 경고를 출력합니다.
- 요청은 1~2초 후 처리합니다. 플레이어가 사망하면 추가 처리를 하지 않고 즉시 종료합니다.
- 공간 내부와 플레이어 기록에 대한 질문에는 답변할 수 있습니다. 직접 출입·이송 요청은 계속 제한됩니다.
- '그'에 대해서는 사실 여부를 확인할 수 있는 스무고개형 예/아니요 질문만 허용합니다. 정체·위치·상세 정보를 직접 알려 달라는 요청, 위치 조작, 접촉은 허용되지 않습니다.
- 원거리 공격 시도는 수리되지만 실제 영향을 주지 못하며, 1~2초 후 무효 결과를 보고합니다.
- 별도 서버 및 API 없이 JavaScript만으로 실행됩니다. 컴퓨터 비프음과 간헐적 팬 소음을 재생할 수 있습니다.
- 게임은 단일 파일 `index.html`을 기준으로 배포합니다.
- 전체 실행 파일은 `PLAY.html`로 별도로 제공되며, `index.html`과 내용이 동일합니다.

본 디렉터리는 기존 `연명 강령`과 기능을 공유하지 않습니다.
