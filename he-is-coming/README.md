# 그가 오고 있습니다

검은 모니터에서 진행하는 100초 실시간 텍스트 명령형 공포 탈출 게임입니다.

- 실행: `index.html`을 브라우저에서 열거나 GitHub Pages에서 같은 경로로 접근합니다.
- 본 폴더의 `index.html`은 스타일, 동작 코드, 사운드 생성기를 모두 포함한 단일 파일입니다.
- 시작 버튼을 누르기 전까지 시간은 흐르지 않으며, 요청은 1~2초 후 처리됩니다.
- 100KM 거리에서 시작하여 1초당 1KM 접근합니다. 30·60·90초와 마지막 10초 구간에 경고가 출력됩니다.
- Web Audio API에서 컴퓨터 비프음과 팬 소음을 생성합니다. 소리를 끌 수 있습니다.
- 정체·위치·접촉, 광역 파괴, 방 이탈 및 파괴 요청은 거부됩니다.

현재는 네트워크 호출 및 유료 모델을 사용하지 않는 규칙 기반 버전입니다. 자유로운 입력을 받아 대부분의 요청에 응답하지만 자연어의 모든 의미를 해석하지는 못합니다. 미공개 설정의 원문은 클라이언트에 저장하지 않았습니다.

본 게임은 기존 `연명 강령`과 코드를 공유하지 않는 독립된 하위 디렉터리입니다.
