[지시서의 충돌·애매한 부분 처리 원칙]
표시 설명보다 구조화된 ‘즉시 효과 / 매일 종료 시 / 지속 보너스’ 데이터를 우선했습니다.
· [001] 쌀 한 되에 좁쌀 서 말: 원본 delay(다음 날 행운 +1)가 이번 수정 지시서에는 없으므로 제거함.
· [035] 어젯밤에 그 달력: ‘불길한 운명 증가 / 파탄 +1’은 구입 시 단 한 번 누적. 매일 반복하지 않음.
· [045],[059],[060],[066],[070]과 일부 다른 문자의 ‘지속 보너스: 파탄 ±n’도 획득 시 1회 누적으로 정규화. 패시브 유지하는 동안 매일 같은 수치를 재적용하지 않음.
· [067] 그 누구의 첫 번째 숨: 표시 설명의 매일 정신력 -11과 구조화된 ‘매일 효과’의 -12가 불일치하므로 -12를 우선 적용.
· [069] 공문 제목이 매우 긴 문자: 원문에서 즉시 효과와 매일 효과가 같은 줄에 병합돼 있어 분리하여 재기록.
· [070] 남은이름은너: 표시 설명에 없는 건강 -12가 ‘매일 종료 시’에 있으므로 건강 -12도 실제 적용.
· [073] 벼락 맞은 옻나무: 표시 설명 정신력 -25 vs 구조화된 매일 -15가 불일치하므로 매일 -15를 적용.
· 유령의 기존 패시브 중 ‘매일 자금 +50,000/+30,000’은 운영비 대비 과도해 +16,000/+13,000으로 하향.
· 사용되지 않는 CSS 선택자(클래스)를 삭제하여 죽은 레이아웃 규칙을 정리.
· 안정적인 12일 생존을 목표로 새 게임 기본 식사를 저가 메뉴로 변경하고 생존형 프리셋의 알바 시간을 늘리고 정화 1회를 줄임.
· 기존 세이브의 음식 인덱스 0~25를 개편된 12종 메뉴로 이전함. 취소되거나 미보유인 음식은 따뜻한 국밥으로 대체.

[밸런스]
· 상점 가격은 등급별 지정 범위 이내. 삭제 확률 93/78/58/33% (특수 효과로 보정, 상한 97%).
· 무작위 이벤트·패시브 등 여러 경로에서 이득/손실이 발생하므로 개별 수치만으로 체감 밸런스를 완전히 확정할 수 없음.
· 12일 생존 모의실험 (생존형 프리셋, 기본 식사, 강령/문자 상점 보상 선택 건너뜀, 고정 시드 200회): 200/200 생존. 이는 제한된 시나리오이지 게임 전체 난이도 보증이 아님.

[데이터 파일 수정 위치]
· data.js: 기본 문자/유령/식사/사건
· expansion.js: 추가 문자/유령/유품/식사/사건 + 실제값에서 표시문구 생성
· engine.js: 즉시/일일/조건/제거/강령/파탄/해방 결과 및 세이브 이전
· app.js: 제거 확률, 소원 선택지, 상점 가격 및 게임 UI
· meal_index_mapping.json: 이전 버전 음식 번호 대응표

원문과 다른 이름·가격·효과가 있는 경우 반드시 편집 데이터를 먼저 확인하고 engine.js의 직접 수식을 동시에 대조할 것.
